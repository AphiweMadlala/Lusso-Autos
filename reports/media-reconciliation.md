# Media reconciliation

Generated by `scripts/process-media.mjs` (downloads, integrity checks, hashing, WebP derivatives) and verified visually with `scripts/tools/contact-sheet.mjs`. Machine record: `data/media-manifest.json`. Every file in `public/images/` traces to an `originalUrl` in the manifest.

## Sources used

| Source | Ownership | Used for | Notes |
|---|---|---|---|
| lussoauto.co.za vehicle-page galleries | Lusso-owned domain | 13 current cars | Preferred: Lusso's own gallery order, and often larger originals (the 550 Maranello at 2560×1920) |
| AutoTrader dealer galleries (`img.autotrader.co.za/<id>` originals) | Uploaded by Lusso (dealer 113036) | 6 current cars with no Lusso-site page | Same Lusso studio photography; **no marketplace watermark** on originals (checked) |
| lussoauto.co.za Sold portfolio | Lusso-owned | 73 sold collector cars | One image per car |
| Instagram | — | **Not used** | Not accessible (see research audit §1) |

Not used, by rule: manufacturer imagery, stock, other dealers' photos, Google Images, and any screenshots. The two sources were **never mixed for one car**, which would otherwise create duplicates.

## Sold archive verification

All 73 downloaded sold images were checked on contact sheets against their Sold-page titles; **all match**. Notes:
- "Ferrari Scuderia" shows an F430 Scuderia (stripes, bumper), displayed as "Ferrari 430 Scuderia" (evidence in `curation.json`).
- The two Huracán photos are outdoor/garage snapshots rather than studio shots. They are kept in the register but not featured.
- Team and showroom imagery was never assigned to vehicles: sold images are one-per-car image boxes, and vehicle galleries come from per-car pages only.

## Derivatives

- WebP at quality 82, widths 480, 800, and the native width (or 1600 when the source is larger). `srcset` + `sizes` + explicit `width`/`height` everywhere; `loading="lazy"` except LCP candidates (`fetchpriority="high"`, preloaded on the home page).
- `public/images/` totals 118 MB (vehicles 95 MB, sold 23 MB). The build copies only referenced folders; `dist/` is about 100 MB.
- Originals are cached in `media/originals/` (git-ignored, reproducible from the manifest URLs).

## Re-running

```bash
npm run fetch:autotrader   # refresh listings (keeps previous successes, retries failures)
node scripts/fetch-lusso-site.mjs
npm run data:vehicles
npm run media              # downloads new originals, rebuilds derivatives, updates manifest
node scripts/tools/contact-sheet.mjs vehicles /tmp/sheets 24 heroes   # visual hero check
```
